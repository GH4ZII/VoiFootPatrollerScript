# VOI Foot Patroller – AutoFill

A simple JavaScript userscript that automatically sets default values when scanning scooters in VOI Foot Patroller.

## Features
- **Repark reason:** Tidying
- **Rack location accuracy:** No rack
- Automatically fills both fields for each new scooter.
- Does not modify photos or submit registrations.

## Installation
1. Install **Userscripts** on your iPhone.
2. Enable the extension in Safari settings.
3. Add `voi-footpatroller-autofill-v2.user.js` to your Userscripts folder.
4. Open https://footpatroller.voiable2.voi.com/ in Safari.
5. Scan a scooter and verify the selected values.

## Technologies
- JavaScript
- Safari Userscripts
- DOM manipulation

## Note
Designed for simplifying repetitive form inputs during parking patrols. Always verify the information before submitting a registration. Use only with employer approval.
